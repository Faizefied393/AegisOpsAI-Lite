# Business case — fictional financial services SOC

**Problem:** A small SOC needs consistent alert triage and business-oriented prioritization.

**Stakeholders:** SOC analysts, security engineering, IT operations, CISO, risk/compliance.

**MVP value proposition:** Consolidate sample events, apply transparent rules, generate evidence-grounded investigation drafts, and expose asset-prioritized risk in one view.

**KPIs to measure in a future controlled study:** alert precision/recall, analyst review time, unsupported AI claims per report, false-positive rate, investigation completeness, and cost per investigated case.

**ROI methodology:** Measure median analyst minutes on the same cases with and without assistance; multiply verified time savings by fully loaded labor cost; subtract model hosting, implementation, maintenance, and review costs. Do not report hypothetical savings as actual results.

**Build vs buy:** This educational reference does not replace Wazuh, Microsoft Sentinel, Splunk, or enterprise SOAR. It demonstrates custom integration and engineering decision-making.

**Risks:** Model hallucination, incomplete logs, misleading risk scores, privacy leakage, API-key misuse, and false confidence in synthetic tests.
